Seminarium is an app made for Utah Tech University to use during Trailblazer Connections. The app helps students to schedule desired seminars, allowing them to have an easy way to organize their day, and give useful data back to the school to make adjustments for the next year.

Although originally intended to have students continue this project every year, Utah Tech University has changed how they structure the Trailblazers Connections event.
